Web Search is a search API that returns URLs and metadata for any query. Use it from a [Workers Binding](/web-search/get-started/#workers-binding), the [REST API](/web-search/get-started/#rest-api), or any [MCP client](/web-search/mcp-server/).

## Use cases

- **AI agents that need real-time information**: give agents the ability to search the web as a tool call, then fetch and act on the results
- **Grounding LLM responses**: reduce hallucinations by searching for current information before generating a response
- **Multi-step research**: search across queries, fetch content from the best results with [Browser Run](/browser-run/), and synthesize across multiple sources
- **MCP tool for coding assistants**: use Web Search from Claude Code, Cursor, OpenCode, or any MCP client

## Key features

{/* TODO: Update /web-search/mcp-server/ link once the web-search-specific MCP server page exists */}

- **Composable**: Returns URLs and metadata only. Pair with [Browser Run](/browser-run/) to fetch full content, extract structured data, or take screenshots of any result
- **Agent-ready**: Drop-in tools for the [Agents SDK](/web-search/ai-integration/agents-sdk/), [MCP](/web-search/mcp-server/), and [AI SDK](/web-search/ai-integration/ai-sdk/) that work with popular AI frameworks
- **Multiple integration paths**: Use Web Search from a [Workers Binding](/web-search/get-started/#workers-binding), the [REST API](/web-search/get-started/#rest-api), or any [MCP client](/web-search/mcp-server/)

## Web Search vs AI Search

Web Search and [AI Search](/ai-search/) are different products for different jobs. Web Search discovers URLs on the public web. AI Search searches specific content you define. Refer to [Discovery and content retrieval](/web-search/concepts/how-web-search-works/#web-search-vs-ai-search) for a detailed comparison.
