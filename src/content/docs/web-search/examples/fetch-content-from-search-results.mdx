Web Search returns URLs and metadata. To work with the actual page content, pair it with [Browser Run](/browser-run/). The examples below show two common output formats.

## Get markdown

Fetch the full page content as markdown using [Browser Run /markdown](/browser-run/quick-actions/markdown-endpoint/). Good for feeding content into an LLM.

<Tabs syncKey="integration">
<TabItem label="REST API">

```bash
# 1. Search for relevant pages
RESULTS=$(curl -s -X POST \
  https://api.cloudflare.com/client/v4/accounts/{account_id}/websearch/search \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "how to deploy Cloudflare Workers",
    "limit": 5
  }')

# 2. Get markdown for the first result using Browser Run /markdown
URL=$(echo $RESULTS | jq -r '.result.items[0].url')

curl -X POST \
  https://api.cloudflare.com/client/v4/accounts/{account_id}/browser-rendering/markdown \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "'"$URL"'"
  }'
```

</TabItem>
<TabItem label="Workers Binding">

<TypeScriptExample>

```ts
export default {
	async fetch(request, env): Promise<Response> {
		const { items } = await env.WEBSEARCH.search({
			query: "how to deploy Cloudflare Workers",
			limit: 5,
		});

		const pages = await Promise.all(
			items.map(async (r) => {
				const response = await env.BROWSER.quickAction("markdown", {
					url: r.url,
				});
				const content = await response.text();
				return { title: r.title, url: r.url, content };
			}),
		);

		return Response.json(pages);
	},
} satisfies ExportedHandler<Env>;
```

</TypeScriptExample>

</TabItem>
</Tabs>

## Get HTML

Fetch the fully rendered HTML using [Browser Run /content](/browser-run/quick-actions/content-endpoint/). Browser Run executes JavaScript before returning the HTML, so this captures content that would not appear in a simple `fetch()` against the same URL. Useful when you need the full page structure, or are working with sites that load content dynamically after the page first opens.

<Tabs syncKey="integration">
<TabItem label="REST API">

```bash
# 1. Search for relevant pages
RESULTS=$(curl -s -X POST \
  https://api.cloudflare.com/client/v4/accounts/{account_id}/websearch/search \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "Cloudflare status page",
    "limit": 5
  }')

# 2. Get rendered HTML for the first result using Browser Run /content
URL=$(echo $RESULTS | jq -r '.result.items[0].url')

curl -X POST \
  https://api.cloudflare.com/client/v4/accounts/{account_id}/browser-rendering/content \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "'"$URL"'"
  }'
```

</TabItem>
<TabItem label="Workers Binding">

<TypeScriptExample>

```ts

```

## Other Browser Run Quick Actions

Markdown and HTML are two output formats. [Browser Run Quick Actions](/browser-run/quick-actions/) offers several others that pair well with Web Search results:

- [`/json`](/browser-run/quick-actions/json-endpoint/): extract structured JSON data using an AI prompt and schema. Refer to [Search and extract structured data](/web-search/examples/search-and-extract-structured-data/) for an example.
- [`/screenshot`](/browser-run/quick-actions/screenshot-endpoint/): capture a screenshot of each result page.
- [`/pdf`](/browser-run/quick-actions/pdf-endpoint/): generate a PDF of each result page.
- [`/scrape`](/browser-run/quick-actions/scrape-endpoint/): extract data from specific elements using CSS selectors.
- [`/links`](/browser-run/quick-actions/links-endpoint/): extract all links from a page, including hidden ones.
- [`/snapshot`](/browser-run/quick-actions/snapshot/): capture both HTML and a screenshot in a single request.
- [`/crawl`](/browser-run/quick-actions/crawl-endpoint/): scrape a page and follow its links across the site, with configurable depth.

The same pattern shown above applies: search with Web Search, then pass each result URL to the Quick Action of your choice.
