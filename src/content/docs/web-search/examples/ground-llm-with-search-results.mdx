LLMs have a training data cutoff date. Any information published after that date is not available to the model, so questions about recent events, product updates, or current data will produce outdated or hallucinated answers. Grounding solves this by injecting current information into the prompt so the model can answer using real-time context instead of relying on its training data alone.

This example passes search result metadata (titles, URLs, and descriptions) directly to a model as context. The LLM can use this to produce a response grounded in real-time search results, with citations back to the source URLs.

This is the lightweight version of grounding: no page content is fetched, so it is fast and uses no [Browser Run](/browser-run/) quota. The tradeoff is that the LLM only sees short descriptions, not full articles. For queries where titles and snippets provide enough signal (trending topics, factual lookups, news summaries), this works well.

For deeper grounding where the LLM needs to read full page content, add a [Browser Run](/browser-run/) fetch step between search and the LLM call. The [Build a web research agent](/web-search/tutorials/agent-web-research/) tutorial shows this full pattern.

<TabItem label="REST API">

```bash
# 1. Search the web
RESULTS=$(curl -s -X POST \
  https://api.cloudflare.com/client/v4/accounts/{account_id}/websearch/search \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "Cloudflare Q1 2026 earnings",
    "limit": 5
  }')

# 2. Build context from the results and pass it to Workers AI
CONTEXT=$(echo $RESULTS | jq -r '.result.items | to_entries | map("[\(.key + 1)] \(.value.title)\n\(.value.url)\n\(.value.description)") | join("\n\n")')

curl -X POST \
  https://api.cloudflare.com/client/v4/accounts/{account_id}/ai/run/@cf/moonshotai/kimi-k2.5 \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "Content-Type: application/json" \
  -d "$(jq -n --arg ctx "$CONTEXT" '{
    messages: [
      {role: "system", content: "Answer the user using these search results. Cite sources by number.\n\n\($ctx)"},
      {role: "user", content: "Cloudflare Q1 2026 earnings"}
    ]
  }')"
```

<TabItem label="Workers Binding">

```ts
export default {
	async fetch(request, env): Promise<Response> {
		try {
			const query = "Cloudflare Q1 2026 earnings";

			const { items } = await env.WEBSEARCH.search({ query, limit: 5 });

			const context = items
				.map(
					(r, i) =>
						`[${i + 1}] ${r.title}\n${r.url}\n${r.description ?? ""}`,
				)
				.join("\n\n");

			const answer = await env.AI.run("@cf/moonshotai/kimi-k2.5", {
				messages: [
					{
						role: "system",
						content: `Answer the user using these search results. Cite sources by number.\n\n${context}`,
					},
					{ role: "user", content: query },
				],
			});

			return Response.json({ answer, sources: items });
		} catch (e) {
			return Response.json({ error: String(e) }, { status: 500 });
		}
	},
} satisfies ExportedHandler<Env>;
```
