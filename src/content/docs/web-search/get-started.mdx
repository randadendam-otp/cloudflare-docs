This guide walks you through setting up Web Search and running your first query. Choose the method that fits your setup:

- [**Workers Binding**](#workers-binding): the recommended method if you are building on [Cloudflare Workers](/workers/). Authentication is handled automatically through the binding.
- [**REST API**](#rest-api): for non-Workers applications. Requires a Cloudflare account and [API token](https://dash.cloudflare.com/profile/api-tokens).

## Workers Binding

### Prerequisites

- A [Cloudflare account](https://dash.cloudflare.com/sign-up)
- A [Workers](/workers/) project

If you do not have a Workers project yet, create one:

<PackageManagers type="create" pkg="cloudflare@latest" args="web-search-demo" />

### Set up the binding

<Steps>

1. Add the `web_search` binding to your Wrangler configuration:

	<WranglerConfig>

	```toml
	name = "web-search-demo"
	main = "src/index.ts"
	compatibility_date = "$today"

	[web_search]
	binding = "WEBSEARCH"
	```

	</WranglerConfig>

2. Use the binding in your Worker to search the web:

	<TypeScriptExample>

	```ts
	export default {
		async fetch(request, env): Promise<Response> {
			const { items, metadata } = await env.WEBSEARCH.search({
				query: "latest Cloudflare blog posts",
				limit: 5,
			});

			return Response.json({
				results: items.map((r) => ({
					title: r.title,
					url: r.url,
					description: r.description,
				})),
				metadata,
			});
		},
	} satisfies ExportedHandler<Env>;
	```

	</TypeScriptExample>

3. Run your Worker locally to test:

	<PackageManagers type="exec" pkg="wrangler" args="dev" />

</Steps>

## REST API

### Prerequisites

- A [Cloudflare account](https://dash.cloudflare.com/sign-up)
- An [API token](https://dash.cloudflare.com/profile/api-tokens) with the **Web Search Run** permission

### Send a request

Send a `POST` request to the Web Search endpoint:

{/* TODO: Replace with <APIRequest /> once /accounts/{account_id}/websearch/search is published in the Cloudflare OpenAPI schema. */}

```sh
curl --request POST \
  --url https://api.cloudflare.com/client/v4/accounts/$CLOUDFLARE_ACCOUNT_ID/websearch/search \
  --header "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  --header "Content-Type: application/json" \
  --data '{
    "query": "latest Cloudflare blog posts",
    "limit": 5
  }'
```

## Request parameters

| Parameter | Type     | Required | Description                                                  |
| --------- | -------- | -------- | ------------------------------------------------------------ |
| `query`   | `string` | Yes      | The search query. Max length: 1,024 characters.              |
| `limit`   | `number` | No       | Maximum number of results to return. Default `10`, max `20`. |

### Result fields

Each result includes a guaranteed set of fields plus optional fields that depend on what metadata the indexed page exposes.

**Always present:**

| Field   | Type     | Description                    |
| ------- | -------- | ------------------------------ |
| `url`   | `string` | The canonical URL of the page. |
| `title` | `string` | The page title.                |

**Optional** (may be missing depending on page metadata):

| Field              | Type     | Description                                                                                                           |
| ------------------ | -------- | --------------------------------------------------------------------------------------------------------------------- |
| `description`      | `string` | Page-level description, usually from the page's meta description tag. May be empty.                                   |
| `imageUrl`         | `string` | Preview image URL from OpenGraph or similar. REST API: `image_url`.                                                   |
| `faviconUrl`       | `string` | Favicon URL for the page's domain. May be missing for some sites. REST API: `favicon_url`.                            |
| `lastModifiedDate` | `string` | ISO-8601 timestamp of when the page was last modified. Many sites do not expose this. REST API: `last_modified_date`. |
